# UpliftJEE Telegram Automation Bot

Production Telegram bot with **Smart AI + n8n automation** for UpliftJEE ed-tech platform.

## Features
- Real-time auto-replies to student queries
- Smart AI fallback system using Gemini 2.5 Flash
- n8n workflow automation (webhooks, JSON configs, API integrations)
- Dynamic thinking budget for simple vs hard questions
- Multi-session handling

## Tech Stack
- **Python + Pyrogram** → Telegram Bot
- **n8n** → Workflow automation
- **Google Gemini (Vertex AI)** → AI responses
- **DigitalOcean** → Live deployment

## Repository Contents
- `config/` → All workflow and config JSON files
- `ai_helper_example.py` → Safe version of AI helper (credentials removed)
- `bot` → Main bot file
- `images/` & `screenshots/` → Supporting files

## Note
- Sensitive files (credentials, session files) are **excluded** using `.gitignore`
- Use `ai_helper_example.py` as reference and add your credentials locally
